# CLI

Terminal chat with personas, tools, optional mic dictation, and optional TTS.

## Run

```sh
kaja
```

## Uninstall

```sh
rm ~/.local/bin/kaja
```

## Develop

```sh
bun install
bun start
```

### Test / lint

```sh
bun test
bun lint # write immediately
```
